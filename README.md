# CPI ICT Club - Learning & Community Platform 🚀

A modern, professional, and responsive web platform for **CPI ICT Club** built entirely with **HTML5, CSS3, and Vanilla JavaScript** (Zero external dependencies or frameworks).

![CPI ICT Club Banner](https://images.unsplash.com/photo-1517694712202-14dd9538aa97?auto=format&fit=crop&w=1200&q=80)

---

## 🌟 Key Features

- **⚡ Modern & Responsive UI**: Built with pure CSS3 custom properties, glassmorphism, fluid typography, and dark/light mode toggle.
- **🎨 Interactive Hero Section**: Dynamic typing animation, interactive HTML5 canvas particle background, and glowing terminal card.
- **📚 Curated Learning Hub**: 12+ tech tracks (HTML, CSS, JS, React, Python, DSA, Networks, DBMS, Git, UI/UX, CyberSec) with multi-criteria real-time search and difficulty filters.
- **🎓 Courses & Bootcamps**: Interactive curriculums, lesson breakdown modals, progress bars, and instant enrollment.
- **📄 Academic Study Notes**: Searchable PDF repository for semester exams with download simulations.
- **💻 Coding Challenges & Developer Toolkit**: Algorithmic problem solver with expandable solutions, copy-to-clipboard code snippets, and cheat sheets.
- **🏆 Events & Hackathons**: Live status badges, detailed agenda modals, and interactive event registration forms.
- **💼 Career & Internships**: Verified student opportunities, tech scholarships, resume checklists, and interview playbooks.
- **🗺️ Interactive Learning Roadmaps**: Clickable milestone checkpoints with progress tracked and saved in `localStorage`.
- **🚀 Projects Showcase**: Student innovation gallery with GitHub and Live Demo triggers + "Submit Your Project" modal.
- **👥 Leadership & Mentorship Team**: Executive committee, technical leads, and volunteer profiles.
- **🖼️ Photo Gallery**: Categorized photo albums with fullscreen keyboard-navigated Lightbox.
- **❓ FAQ Accordion**: Expandable frequently asked questions with smooth micro-animations.
- **🔍 Global Search (`Ctrl + K`)**: Instant search across all resources, courses, notes, and events.
- **⭐ Bookmarks Drawer**: Save favorite learning resources with `localStorage` persistence.

## 🚀 Getting Started

No build tools, npm packages, or bundlers required!

1. Clone the repository:
   ```bash
   git clone https://github.com/rhRafi247/ICT-CLUB.git
   ```
2. Open `index.html` in your favorite browser.
